## Fixed classification rules

The scorer validates each original bundle with the original independent
accounting validator. Target eligibility and pairing use the original truth
obligation, not guessed endpoints or observed correctness. All amounts remain
integer sompi. Exact hits and `10*abs(guess-actual) <= actual` hits are separate.

For each selected construction record separately:

1. Whether hypothesized PAY inputs equal the actual input set.
2. Whether receipt-side payout legs form a **closed accounting flow** from the
   actual receipt plus the specified known additional note, if present.
3. The same closed-flow test for actual sender change; empty legs qualify only
   for actual zero change with no additional note.
4. Whether either leg merely intersects actual transitive note ancestry,
   including ancestry that crosses public payout/re-entry bridges. Distinguish
   private-only ancestry from paths involving native re-entry.
5. Whether receipt legs instead follow sender change, or change legs follow
   the receipt; whether selected payout owners agree with the relevant owner.

A closed flow consumes only its current note frontier, accounts for all selected
payouts and their fees, adds each positive private output, and finishes with no
frontier. Its initial value must equal the reported residue plus the known
additional note. A missing leg, unrelated extra input, unselected intervening
PAY/MERGE, false additional note, fee error or wrong residue fails closure.
A late-born additional note is allowed if it is actually consumed in the
selected flow; it is not assumed available before its actual birth.

Report exact receipt-and-change constructions, input-and-change-only matches,
receipt-only matches, change-only matches, ancestry without closure, and
unrelated selected payouts. Preserve wrong-branch flags independently. For each
target report whether **any** and whether **all** retained unique constructions
match the relevant path. Correct numerical guesses can have false supports;
false identity guesses can coexist with correct value paths.

Structural ancestry is a set of possible sources. After mixing, splitting or
re-entry it does not allocate particular sompi to descendants. Even a matching
closed construction does not prove the observer uniquely recovered a fact or
assigned it high probability. No new uniqueness/privacy certificate is issued.
