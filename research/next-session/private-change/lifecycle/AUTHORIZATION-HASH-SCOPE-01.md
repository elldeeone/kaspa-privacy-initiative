# Actual-live authorization fingerprints

The sealed actual-live packets retain original SHA-256 identities for the root-issued one-stage release, submit request and equal durable intents. These containers refer only to the public trial identity and selected public body, context and native-validation artifacts. Their hashes record operational authorization provenance; raw filesystem paths are omitted from the exported authorization selection.

`CONFIRMED-STAGE.json` uses the historical field name `original_public_input_identities` for both selected public transaction data and these operational container fingerprints. This does not mean that wallet private requests or cryptographic inputs were hashed or published. No wallet request, backup, seed, witness, private invoice, private owner-to-CM map, discarded attempt or unbroadcast main alternative is included.

This additive clarification preserves every source, stage packet, manifest and whole-source ledger byte. It adds no financial, privacy or independent-consensus claim.
