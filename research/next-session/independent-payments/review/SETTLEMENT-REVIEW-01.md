# Public transcript adversarial review

ACK for a bounded public semantic checker, not a shared-settlement proof or
cheaper native route. Reviewed `policy.py`, `wire.py`, `fixtures.py`,
`transcript.py`, `run.py` and selected public verifier adapters, including the
actual indexed-NF, CM, state/body and native-value paths.

The checker independently binds selected starting point/state/reserve, exact
immutable policy tail, official v1 IDs, ordered CM/cipher digests and aligned
empty-subtree update, both sequential indexed-NF absences/inserts and exact
successor/payout bodies. Genuine proofs remain a separate actual predicate.
Supported contexts are strictly typed and canonical; B1600/DAA0/storage mass
are explicitly selected-profile checks rather than intrinsic authorization.
Externally selected valid starting history/empty suffix remain premises.

native fixed locktime/gas/subnetwork/sequence checks. All four coherently re-IDed

`2af81d31b840da5618ebd68d3c7861a32488eaa58201209385b4c9fc50486645`.
The implementation now checks all four native constants independently of the
budget profile. The independent [post-fix control](settlement_header_checks.py)
and [result](SETTLEMENT-HEADER-GAP-02.json) bind source
`fb9663d1e7b135e5c5f3832fe5bbb0a8b5ceb458a3cf33a5838026153553ed45`:
four real G16 predicates remain true, all four semantic decisions reject the
exact fixed-header category. These controls use official normalization and no
new native VM calls. The matching pre-fix source is separately retained and
explicitly labelled as an exact-hash reconstruction.

The lane's `settlement/attempt-02/RESULTS.json` records the ordered wide/compact
positive, 43 individual controls and three sequence negatives. Fresh privately
valid occupied-NF and wrong-next-CM-root proofs stay cryptographically true but
fail public semantics. Competing, duplicated and reversed actions fail ordered
settlement. Rejected prefixes cannot later become valid. Exact fee accounting
retains 2,000 sompi for these deliberately underpaid public canaries; claiming
1,000 with unchanged effects rejects. No generic report acceptance flag stands
in for proof verification.

The experiment specifies what a future aggregate must authorize. It neither
executes a new native policy nor lowers old authorized fees. A future design
still needs authenticated combined state/output/NF/fee/rebate semantics, actual
matched verification costs and an owner-local private unilateral fallback.
Per-action public partitions, timing/amount leaks, data retention, setup
soundness and accepted currentness remain outside this checker’s guarantees.
