# Separate combined public runtime

The host-only `poc/four-wallet-live/prepare_runtime.py` will copy the externally
selected accepted owner base02 into a fresh destination, then add only ten
fixed live runtime sources from live source02, the fixed byte-verifier helper,
and the selected chain02 anchor/fetch entry points. It will not execute any
staged source, ELF, SDK, prover, validator or network operation.

Before reading input documents, metadata-exclude all eight original backup
files and all eight complete owner directories across the separately supplied
local/live trial roots. Public reads require canonical nonsymlink paths,
regular files, no excluded directory/inode, an opened inode matching the
metadata check before the first byte, stable metadata/length, and expected
whole-file SHA. Enumerate and metadata-check every base/addition member before
reading the first member. No backup bytes or backup hashes are collected.

Use the exact typed owner base inventory SHA
`0a2d5964f998f6e26e1bee4872e857470493a0deb3c74f54d26e11ff4d24b6c7`,
live source02 SHA
`c14ae7f00beb0f78f21b2c28f50daa79a9cc54407dc51053ad737145cb91e402`,
and chain02 SHA
`83053db87ba088fa8734aa6acf59896fddb7c538c8dbb310feaa6cbbfa3de7f9`.
Require the coherent lifecycle contracts `a4835dac…` and chain replay
`2f8985eb…`, exact current SDK3 pins, selected financial profile `41c60779…`,
and all four installed executable hashes/lengths matching that profile.

The result is a new typed generic software inventory. Copies are mode0400 for
sources/metadata/SDK and0500 for selected executables; files use exclusive
creation and no hard links. Existing owner runtime01/02 and prior publication
packets remain physically unchanged. Public receipts expose finite file/byte
counts and public source/inventory/profile/SDK joins only, with no private
paths, owner maps, inode identities or backup-derived digests.

Root reviews the retained source plan/freeze before the public build. This
recipe creates no execution or live-submission permission and establishes no
accepted balance, proof validity, privacy or trial readiness.
