New synthetic research package for the prospectively reviewed
[method](../../research/next-session/compact-batch/privacy/PLAN-PROPOSED-01.md).
No old corpus, observer, protocol, wallet or proof parameter is changed.

The exact Int/Bool model handles sparse CM positions, one-real-input known wallet
policy, full native cashouts, current participant NF/value facts, all-prefix
backing, terminal drainage and original funding lineage. Business-counterparty
labels never become ingress-lineage equations. SAT alternatives are only
arithmetic assignments; cryptographic ownership histories and equal probabilities
are not established. Human identity is NOT_MODELLED in the exact relation.

`observe.py` reads one strict public JSON on stdin and no files. `certificate.py`
independently validates integer assignments without Z3 or generator imports.
A public-only incomplete constructive witness search accelerates SAT without
adding constraints; every typed query and grouped permutation is independently
checked; completeR0
consequences accelerate exact matching without using private truth. The first
UNKNOWN halts further checks in that view and leaves unqueried rows incomplete.
Explicit NONE alternatives prevent a lone feasible cashout from being mistaken
for a forced link of a dummy, self-change or unspent note.

with fresh disposable model seeds and correct Note168 V at64:72. Continuing

existing actual-slot HMAC formula. All models are DO_NOT_FUND and use domains
separate from any financial trial. The scorer checks supplied Note/CM openings,
public NF/cipher placement, modeled ownership/demand, precise integer fees and
tails. It receives no keys and cannot independently prove secret encryption/NF
preimages; generator/bridge correctness remains an explicit premise.

`run.py` requires a separately pinned root release and frozen sources. The outer
launcher must deny Internet sockets and set4CPU/8GiB/zero-swap limits; sibling

material; actual backups/profiles/witnesses/PKs are never inputs. No heldout
