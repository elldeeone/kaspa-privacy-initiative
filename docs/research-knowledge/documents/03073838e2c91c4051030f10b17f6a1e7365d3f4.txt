# Retained development path-guard failure

Before any selected setup, the first eight metadata-only guard tests produced
seven passes and one positive-case error, twice. The initial code rejected every
ancestor named `.git`. This host has empty placeholder directories at its home
and temporary roots; Git reports them explicitly as non-repositories. Moving the
synthetic test did not resolve that incorrect predicate.

The guard now probes actual Git status at the nearest directory and every marked
ancestor, accepting only the explicit not-a-repository result. A real higher
repository is still rejected even when an invalid nested marker masks normal
discovery. Symlink, owner and private permission checks remain. Ten synthetic
metadata controls pass, including both placeholder and hidden-parent cases.
Actual selected config/shape/new-stage metadata preflight also passes without
reading or hashing a witness. No trial, key or proof was generated by these
tests; the fresh domain and circuit did not change.
