# Compressing the retained two-v6 receipt with the established Groth16 wrapper

Status: the established route compressed the retained paired Succinct receipt
on the RTX 3070 in **4.448 seconds**, without guest re-execution. Independent
CPU SDK verification and the pinned native **0x20 bare predicate** both passed.
The output receipt is 581 bytes; the checked native proof is 128 bytes. This
qualifies a public pair claim, not a state transition or funded pool. Source
and evidence checked 2026-10-22 UTC.

## Decision and executable boundary

Use the existing **RISC Zero 3.0.3 IPC CUDA worker** to compress the retained
paired receipt directly. Do not execute the guest or repeat its STARK proof.
`Prover::compress(&ProverOpts::groth16(), &receipt)` accepts an existing
`InnerReceipt::Succinct`; its implementation runs `identity_p254`, then the
standard Groth16 STARK verifier, while preserving the top-level claim and exact
journal bytes. The identity operation is an additional fixed recursion proof,
not execution of the private-payment guest. [Versioned API](https://docs.rs/risc0-zkvm/3.0.3/risc0_zkvm/trait.Prover.html#tymethod.compress),
[pinned SDK implementation](https://github.com/risc0/risc0/blob/14b5d588dd01cf4f7ba804d8bb0a61264e6ae2c6/risc0/zkvm/src/host/server/prove/mod.rs#L192-L240),
[identity program](https://github.com/risc0/risc0/blob/14b5d588dd01cf4f7ba804d8bb0a61264e6ae2c6/risc0/zkvm/src/host/recursion/prove/mod.rs#L352-L388).

The prepared driver is
`artifacts/groth16-compression-preparation/compress_retained.rs`, SHA256
`61c35817178bd7e28c6792907654ca72fa3bb3e905ec0511e2b6b5472d3d5d1f`.
It is an additive binary for the existing pair proof host, with no new dependency

```text

      fuzzed_msm_results.bin
  compression-work/                  # new, writable public-proof scratch
  compression-run/                   # must not already exist
```

Set `RISC0_PROVER=ipc`, `RISC0_SERVER_PATH` to the fixed CUDA worker,
`RISC0_HOME` to this task-local component root, `RISC0_WORK_DIR` to the new
scratch directory, and `GITHUB_TOKEN` to the empty string. The last setting
prevents rzup from reading the user's gh credential file. `RISC0_DEV_MODE` must
be absent. Do not change `HOME`, `RUSTUP_HOME` or global installations. Recursion
programs are already embedded in the existing worker; no recursion download is
required by `identity_p254`.
[IPC compression](https://github.com/risc0/risc0/blob/14b5d588dd01cf4f7ba804d8bb0a61264e6ae2c6/risc0/zkvm/src/host/client/prove/external.rs#L64-L84),
[rzup environment](https://github.com/risc0/risc0/blob/14b5d588dd01cf4f7ba804d8bb0a61264e6ae2c6/rzup/src/env.rs),
[embedded recursion programs](https://github.com/risc0/risc0/blob/14b5d588dd01cf4f7ba804d8bb0a61264e6ae2c6/risc0/circuit/recursion/src/prove/zkr.rs).

Build the driver in the existing pair-host graph, then run it only after a
separate resource release:

```text
compress_retained SOURCE_RECEIPT FROZEN_SOURCE_SHA256 NEW_OUTPUT_DIRECTORY
```

The controller must pin the actual executable, source receipt and extracted
component files, keep the component read-only, disable network access, watch
CPU/RAM/VRAM and retain the candidate on failure. A timeout, memory failure or
missing component is an operational failure, not rejection of the payment
relation. No automatic guest reproving follows from a compression failure.

## Native consequence and remaining gates

The established vProgs adapter converts a RISC Zero Groth16 seal into a
**128-byte compressed native BN254 proof**. The SDK seal itself uses a different
representation; do not call the raw seal 128 bytes. The existing covenant binds
five public inputs to the standard control root, exact receipt claim and BN254
identity control under its fixed wrapper key. The five-input native base/key
cost is 155,000 mass before covenant, payload and storage costs. This source
bound differs from the large Succinct seal route; it is not a measured pair
settlement cost.
