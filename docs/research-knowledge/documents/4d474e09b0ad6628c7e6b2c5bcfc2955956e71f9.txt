# Public experiment view

The exact allowlist publishes the new run-only CLI/source lock, source
snapshots, selected public fixture, plan, build tests, runtime freeze,
timings, public proof/Auth/VK and cleanup. The fresh uncompressed parameter
file, compiled executable and Cargo caches remain local with original
identities retained. Full manifests referring to them cannot all be
rehashed from Git alone.

The frozen exact-SHA candidate is a separate package owned by the circuit
experiment. This packet includes its byte-identical build snapshot and
records the independent candidate closure. Source snapshots preserve their
original README context; the manifest maps those documentation paths rather
than modifying closed archive bytes.

Rebuilding the runner and its three small tests needs no proving key. A new
execution generates another random setup and VK; it cannot reproduce the
exact recorded key bytes. Public proof verification needs only the published
Auth484/VK328/Proof128 and the unchanged checked verifier API. There is no
old-key loader or automatic native-policy adoption path.

All data here is deliberately public synthetic DO_NOT_FUND research. No
funding, broadcast or chain action occurred in this experiment.
