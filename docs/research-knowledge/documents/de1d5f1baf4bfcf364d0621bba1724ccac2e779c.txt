# Explicit-input local capsule pack controls

Frozen before execution. `pack_local.py` makes local unpublished capsules from
four/five explicit public input paths; it does not scan a directory or upload.
Six public-only questions target pack→production-stage composition, no-PK
recognition, wrong role before PK access, corrupt PK fixed rejection/no index,
software command rejection, and synthetic own-backup hardlink rejection.

Small fake non-Ark keys and PUBLIC_STRUCTURE_ONLY_DO_NOT_FUND history are used.
All actual parameter caches/backups/provers/node/native binaries are unmounted.
No assertion of recognized ownership, native validity, accepted/current state,
public publication or provider retention follows. Preserve errors; do not
change expected outcomes after a result. Actual new-role PK copies remain a
separately scheduled root resource release.
